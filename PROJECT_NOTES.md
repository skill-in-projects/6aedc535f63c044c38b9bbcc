# Project notes

## What the app is for
A simple personal app. It is still early; the user is building it step by step.

## Main screens
- Home (`#/`): the starting screen, with a link bar at the top.
- Notes (`#/notes`): a text box and an Add button. Each added note appears in a list. Notes are kept on screen only (not saved between visits).
